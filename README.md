# HR Attrition & Workforce Insights Dashboard

## 📊 Project Overview
This Power BI dashboard analyzes employee attrition and workforce patterns to help HR teams make data-driven decisions.

## 🔍 Key Insights
- Total Employees: 1470
- Attrition Rate: 16%
- Department-wise & Job Role-wise Attrition
- Gender Distribution
- Salary & Age Impact on Attrition
- Work-Life Balance Analysis
